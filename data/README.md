# Data Dummy ERP Data Check & Tracker

> **Semua data fiktif.**

Setiap sheet adalah satu tabel Excel dengan nama yang sama dengan nama
sheet.

Kode dan tanggal sengaja disimpan sebagai teks supaya spasi, huruf
kecil, nol di depan, dan format tanggal campur tetap utuh.

> **`error_truth` = kunci jawaban.** Jangan dipakai sebagai input rumus
> deteksi, hanya untuk menghitung **recall** dan **precision**.

**Toleransi three-way match yang disarankan:** Rp 1.000.
