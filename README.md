# ERP Data Check & Tracker

Proyek portofolio: workbook Excel yang meniru pekerjaan tim data saat memasukkan data ke ERP.  
Memeriksa akurasi data, merekonsiliasi data sumber dengan data hasil unggah, dan melacak item yang belum selesai.

**Seluruh data adalah dummy (sintetis). Tidak ada data perusahaan nyata dan tidak memakai ERP asli.**

Status: dalam pengerjaan.
